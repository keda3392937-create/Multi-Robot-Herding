# Archived external-cage draft

This directory preserves an earlier generated draft that interpreted the cage as extending
outside the field from `left-down`. The user's latest requirement places the cage inside the
field with its top-left corner equal to the field's `left-up` marker, so this draft is not an
experiment entry point and is intentionally excluded from automatic test collection.

Use `../relative_cage_capture.py` and `../relative_cage_core.py` for the current implementation.
The archived draft imports an older core API and is retained for source comparison only.
